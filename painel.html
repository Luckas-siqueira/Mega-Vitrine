Como configurar o token do GitHub
  1. Abra seus tokens no GitHub. Confira Resource owner: Luckas-siqueira e selecione somente Mega-Vitrine.
  2. Para cadastrar e editar: Contents → Read and write.
  3. Somente para extrair informações automaticamente: também Actions → Read and write. A API da Shopee precisa estar aprovada e configurada.
  4. Copie o valor completo do token para o campo acima e use Testar conexão. Ele é mantido apenas enquanto esta página está aberta.

⚠️ Crie o token apenas na sua conta do GitHub, limitado ao repositório Mega-Vitrine, com permissão Contents: Read and write e expiração curta. Nunca envie o token pelo chat, por prints ou para outras pessoas. Não adicione tokens ao código do site. Não use este painel em dispositivos compartilhados.

O token solicitado aqui é do GitHub. App ID e Secret da Shopee servem apenas à importação automática. Depois de informar o token, use “Cadastrar no GitHub”. Para editar, carregue primeiro o catálogo. Se outro acesso alterar o mesmo produto, o painel bloqueia a edição para evitar perder dados.

Importar produto por link

Cole um link da Shopee para preencher nome, preço, foto e link de afiliado. Confira a categoria sugerida antes de cadastrar. A descrição completa pode precisar ser preenchida por você.

A extração automática precisa de acesso aprovado à Open API da Shopee. Se sua conta ainda não tem esse acesso, use Usar link no cadastro manual; gerar outro token do GitHub não libera a API da Shopee.

Acompanhar importações no GitHub

Ativar a importação automática
  1. Confira o acesso à Open API no painel de afiliados Shopee. A aprovação depende da Shopee.
  2. Guarde o App ID e o Secret nos Secrets do repositório, com os nomes SHOPEE_APP_ID e SHOPEE_SECRET. Não envie essas chaves pelo chat.
  3. O token do GitHub usado neste painel precisa de Contents: Read and write e Actions: Read and write, apenas para Mega-Vitrine.

O cadastro manual continua disponível. A importação salva um rascunho e as fotos no GitHub; o produto só entra na vitrine depois de você conferir e cadastrar.
